Springbolt Studio — Style Guide

Reference this page before building any new page. Every color, type size, button, and motion pattern used across the site is documented here with the exact class names to reuse from styles.css / site.js. Don't introduce new colors, fonts, or button shapes — extend this system instead.

Typography

Font is Inter everywhere, no exceptions. Titles are semibold (600) — never the 700/800 weights. Body copy is regular 400.

Body copy is Inter Regular at 18px with 1.75 line-height. This is the size and weight used for every paragraph on the site — do not go smaller than 16px for running text.

Font stack: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif. Weights in use: 400 regular, 500 medium (nav links, subtitle), 600 semibold (all headings, buttons).

Buttons

Always fully rounded (pill). Never use a squared or slightly-rounded button anywhere on the site.

Classes: .btn (base) + one of .btn-primary / .btn-outline (white, for dark backgrounds) / .btn-outline-dark (black, for light backgrounds) / .btn-outline-green (green by default, not just on hover). Add .btn-sm for the smaller card/row size.

Load-in Motion

Two patterns, used site-wide. Scroll down and back up on this page to re-trigger them — see the live homepage for the full effect in context.

1. Heading mask-reveal

Each line (or, for the hero wordmark only, each character) sits in an overflow-hidden mask and slides up into place on scroll.

<h2 class="reveal-heading">
  <span class="reveal-mask"><span class="reveal-line">Line one</span></span>
  <span class="reveal-mask"><span class="reveal-line">Line two</span></span>
</h2>

2. Body copy / buttons — fade + rise

Apple-style: fades in while rising 22px, staggered across siblings inside a .stagger wrapper.

<div class="stagger">
  <p class="fade-in-up">...</p>
  <a class="btn btn-primary fade-in-up">...</a>
</div>

Both require site.js included before </body> — it's what toggles .is-visible via IntersectionObserver. Include it on every page alongside styles.css.
